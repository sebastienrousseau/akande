# Getting support

Thanks for using Àkàndé. Here is the fastest way to get help:

## Read first

Most questions are answered in one of:

- **[README.md](README.md)** - install, quick start, CLI flags, configuration.
- **[DEVELOPMENT.md](DEVELOPMENT.md)** - toolchain setup, local quality gates, test suite.
- **[SECURITY.md](SECURITY.md)** - security policies and vulnerability disclosure guidelines.
- **[`docs/`](docs/)** - architecture and module documentation.

## How to ask for help

- **Bug reports**: File an issue via GitHub using the bug report template. Include reproduction steps, environment details (Python version, OS, audio setup), and full tracebacks.
- **Feature requests**: File an issue via GitHub describing the motivation, proposed design, and alternatives considered.
- **Security vulnerabilities**: Report security vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md). Never post security vulnerability details in public issues or PRs.
