## TL;DR

Àkàndé v0.0.6 is the **catch-up release**.  Eight focused
iterations close Tracks A, B, C, D, and the bulk of E — the
EU AI Act Article 50 controls bind 2 August 2026 and we wanted
the credibility floor in place before then.

What's new since v0.0.5:

- **CI green** — tests, mypy, bandit, pip-audit gate every PR.
  Coverage is at 63 % and ratchets up release-by-release.
- **Streaming + multi-turn + memory** — SSE briefing endpoint,
  SQLite-backed conversation store, Mem0-backed long-term memory.
- **EU AI Act Article 50** — `AKANDE_PROFILE=eu` flips on AI
  disclosure (§1+§5), AudioSeal watermarking (§2), Ed25519-signed
  audit sidecar, GDPR data export/delete CLI, prompt-injection
  envelope, outbound secret scrubbing.
- **Offline mode** — `AKANDE_MODE=offline` refuses every non-local
  provider; `akande install-local` bootstraps Ollama + faster-whisper
  + a starter `.env`.
- **MCP both ways** — `akande mcp serve` exposes Àkàndé's tools to
  Claude Desktop / Cursor / Continue; `akande mcp list` introspects
  upstream MCP servers from a Claude-Desktop-shaped `~/.akande/mcp.json`.
- **Skills** — `briefing`, `web_search`, `weather`, `finance`
  starter set with per-skill consent + `akande skill {list, enable,
  disable, consent, revoke}`.
- **Speech-to-speech seam** — `AKANDE_S2S=openai_realtime` for
  end-to-end S2S over the OpenAI Realtime WebSocket.

## What's intentionally **not** in v0.0.6

These ship in v0.0.7+ — calling them out so operators can plan:

- Voice cloning surface + consent capture flow
- Tauri 2 desktop / mobile / browser extension
- Home Assistant Wyoming satellite + Assist conversation agent
- Wake-word (openWakeWord)
- Sandboxed `python_eval` tool + shell skill
- OAuth skills (calendar / notion / slack)
- Skill marketplace at `akande.co/skills.json`
- Full realtime cascade pipeline (silero-VAD + barge-in +
  partial-transcript streaming) — the **sequential** pipeline
  ships in v0.0.6 as the foundation

## Upgrade path

```bash

```

Breaking changes since v0.0.5: none documented at the public API
surface.  The `LLMProvider` ABC grew `generate_stream` and
`generate_stream_messages`, but the previous methods still work
unchanged so third-party provider plugins keep working.
